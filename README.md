Entry for the [Worst Superpower](https://make.fun/competitions/u-suroto-worst-superpower-461dcdbe?ref=susay21) competition on [make.fun](https://make.fun).

## The entry

`main.py` (Python 3.13, standard library only, no network) writes one line to `/output/entry.txt`, inventing the most useless superpower imaginable:

> I can stop time, but only for the second hand of my own wristwatch.

The ultimate power, reduced to a broken watch: time stops, and the only thing that notices is the wristwatch — which is now simply wrong.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: two runs produce byte-identical files (see `run1/entry.txt` and `run2/entry.txt`).
